# Sakuga Edit – Ideen & Roadmap

Ideensammlung für die nächsten Versionen. Neue Wünsche einfach unten ergänzen.

## Geplant (noch nicht gebaut)

### Flow-Edits (Inspiration: Molob, «Anime Flow Editing»)
- [ ] **Flow-Preset:** weiche, durchgehende Kamerabewegung statt harter Shakes
- [ ] **Bewegungs-Übergänge:** der Übergang führt die Bewegungsrichtung des Clips weiter
- [ ] Starker Motion Blur und sanfte Velocity-Kurven als Standard im Flow-Preset

### Sound-Design
- [ ] Sound-Effekte: **Whoosh** (Übergänge), **Impact/Boom** (Drop), **Riser** (Build-up)
- [ ] Automatisch platzieren **oder** selbst auf die Timeline ziehen

### Look
- [ ] Dunkle, dramatische Color-Grading-Looks (z. B. für Aizen-, Villain- und Dark-Edits)

### Aus Molobs Aizen-Edit (analysiert, gemacht in CapCut)
- [ ] **Farbwechsel auf jedem Beat** (rot → pink → blau → gelb → lila)
- [ ] **Neon-Duotone:** Line-Art und dunkle Clips einfärben (dunkel = Farbe, hell = weiss + Glow)
- [ ] **Partikel-Overlays:** Bokeh, Glitzer, Funken/Glut, pulsieren auf dem Beat
- [ ] **Blitz-Overlay** (lila/goldene Elektro-Blitze um den Charakter)
- [ ] **Blur-Whip-Übergang** (starke Bewegungsunschärfe als Übergang)
- [ ] **Split-Screen-Collage** (mehrere Panels schieben sich ins Bild)
- [ ] **Epische Serifenschrift** (z. B. Cinzel) + Stil «Episch»: silbern, Schatten, leichter Glow, Buchstabe für Buchstabe
- [ ] Looks: **Gold/Feuer**, **Villain-Lila**, **Blut-Rot**
- [ ] Preset **«Villain Flow»**, das alles kombiniert
- [ ] Später (braucht KI): **Text hinter der Person** (Person freistellen)

### Aus 6 weiteren Molob-Edits (Toji, Gojo/Sukuna, Demon Slayer, Gohan, Bleach, Sanji)
**Text ist sein Markenzeichen:**
- [ ] **Doppel-Text:** dasselbe Wort riesig als reine Kontur über den ganzen Screen + klein gefüllt in der Mitte (SIDE, POTENTIAL, YOUR, SH*T)
- [ ] **Neon-Kontur-Text** mit Glow (z. B. blaues MOLOB)
- [ ] **Wort hervorheben:** einzelnes Wort in Akzentfarbe («THE *STRONGEST* SORCERER»), Syntax mit *Sternchen*
- [ ] **Verlauf-Füllung:** Gold, Silber, Lila
- [ ] **3D-Text** (Extrude mit unscharfem Schatten)
- [ ] **Gespiegelter Text**
- [ ] Schriften: Serif wie Cinzel/Trajan, schmal-fett gestapelt («A SMOOTH / CRIMINAL», rot/weiss)
- [ ] **Auto-Text:** Wörter automatisch auf Beats verteilen, im Doppel-Text-Stil
- [ ] **Signatur/Wasserzeichen-Text** (eigener Name, wie «MOLOB»)
- [ ] Später (KI): Text **hinter** der Person

**Effekte & Looks:**
- [ ] **Leuchtende Augen:** Form «Leuchtpunkt» (weicher Glow, Blend Addieren), auf das Auge setzen
- [ ] **Lens-Flare / Anamorph-Streifen** (gelb/blau)
- [ ] **Bokeh-Kreise** (gross, pink/lila) und **Elektro-Blitze** als Overlay
- [ ] Looks: **Lila/Pink-Grade** (Toji), **Rot-Schwarz** (Sukuna), **Eisblau** (Gojo), **Gold**
- [ ] **Invert-Blitz** auf einzelnen Frames, **Zoom-Blur** und **Richtungs-Blur** als Übergang
- [ ] **Split-Screen-Collage** (Sanji-Edit)
